# 시간표 안드로이드 앱

30분 단위(07:00~21:00) 반복 주간 시간표입니다. 주간/요일별 보기, 일정 추가·수정·삭제·복사, 색상, 메모, 시작 전 알림을 지원합니다. 한 주는 월요일부터 시작합니다.

## 빌드 및 설치

1. Android Studio에서 `android` 폴더를 프로젝트로 엽니다.
2. JDK 17과 Android SDK 35를 설치하고 Gradle 동기화를 진행합니다. 명령줄에서는 `gradlew.bat assembleDebug`로 빌드할 수 있습니다.
3. Android 8.0 이상 기기에서 `app`을 실행합니다.
4. 홈 화면 빈 곳을 길게 누른 뒤 **위젯 → 오늘 일정**(목록형) 또는 **주간 시간표**(월~일 격자형)를 선택합니다. 둘 다 추가할 수도 있습니다. 주간 시간표 위젯은 안에서 위아래로 스크롤하여 07:00~21:00 전체를 볼 수 있습니다.

처음 알림을 켜면 알림 권한과 정확한 알람 권한 요청 화면이 표시됩니다. 정확한 알람 권한이 없으면 Android의 절전 정책에 따라 알림이 늦을 수 있습니다. 일정은 기기 안에 저장되며 같은 요일에 매주 반복됩니다.

앱의 **설정**에서 다크/라이트 모드, 프리텐다드/배민 주아체, 두 위젯에 공통으로 적용되는 배경 투명도(0~100%)를 선택합니다. 화면 모드와 폰트도 두 위젯에 반영됩니다. 한 번 저장한 계획 이름은 이후 계획 입력칸에 첫 글자를 입력하면 추천됩니다. 폰트 출처와 배포 조건은 `fonts/`의 안내문을 참고하세요.

GitHub Actions는 `main`에 변경 사항이 올라오면 APK를 빌드하고, `v`로 시작하는 태그가 올라오면 설치용 APK를 GitHub Release에 첨부합니다. 이 APK는 개발용 서명으로 빌드됩니다. 실기기 알림과 위젯 동작은 별도 확인이 필요합니다.
